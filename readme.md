# Rust Practice

A personal repository for learning and experimenting with Rust programming concepts.

## About

This project serves as a playground for exploring Rust features, syntax, and best practices. Currently contains basic examples and will be expanded with more complex programs as I progress through my Rust learning journey.

## Current Project Structure

- **Package Name**: `demo`
- **Rust Edition**: 2021

## Getting Started

### Prerequisites

Make sure you have Rust installed on your system. If not, install it from [rustup.rs](https://rustup.rs/).

### Running the Project

1. Clone the repository:
   ```bash
   git clone https://github.com/harsh-pandhe/rust-practice.git
   cd rust-practice
   ```

2. Build the project:
   ```bash
   cargo build
   ```

3. Run the project:
   ```bash
   cargo run
   ```

4. Run tests (when available):
   ```bash
   cargo test
   ```
